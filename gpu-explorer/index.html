About this project

An independent data analytics portfolio project. Specifications for 46 desktop GPUs were curated and cleaned from public GPU spec datasets. Where retail listings exist in the dataset, price is their mean; otherwise a reference street-price estimate is used (shown alongside the launch MSRP), so cross-generation value comparisons are indicative rather than exact. The 3D model is a procedural illustration scaled from dataset specifications, not an exact product render.
